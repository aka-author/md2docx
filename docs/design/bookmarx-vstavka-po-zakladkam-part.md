# Пошаговый перенос HTML в документ Word по закладкам part_

## Назначение документа

Документ описывает принцип работы этапа html2docx для скрипта bookmarx.vbs. Этап переносит HTML в документ Word не одним блоком на все тело, а отдельными фрагментами. Каждый фрагмент связан с закладкой Word, имя которой начинается с префикса part_. Так сохраняются в выходном DOCX все участки шаблона вне закладок part_, а заменяются только диапазоны, для которых в HTML есть одноименный якорь.

## Место этапа

На вход bookmarx.vbs поступает HTML с якорями name. Якоря с префиксом part_ задают крупные зоны вставки в шаблон DOCX. Якоря с префиксом style_ размечают элементы внутри этих зон для последующего применения имен стилей Word. Способ получения HTML этап не регламентирует. Перечень имен part_ и состав зон согласуют автор HTML и автор шаблона Word; скрипт не проверяет смысл разделов.

Ранее скрипт очищал основной текст шаблона и вставлял HTML целиком, из‑за чего терялось содержимое вне вставки. Новое поведение выполняет точечную замену только по закладкам part_.

## Термины

**HTML** — файл первого аргумента bookmarx.vbs.

**Входной DOCX** — файл второго аргумента: шаблон Word с закладками part_ и стилями, на которые ссылается разметка style_.

**Выходной DOCX** — файл третьего аргумента после вставки фрагментов и применения стилей по style_.

**Якорь part_** — элемент HTML с атрибутом name, значение которого начинается с part_. Фрагмент ограничен парой открывающего и закрывающего тегов этого элемента.

**Закладка part_** — закладка в DOCX с тем же именем, что у якоря part_. Диапазон закладки — область замены.

**Якорь style_** — элемент HTML с атрибутом name, значение которого начинается с style_. После вставки он должен соответствовать закладке style_ в DOCX.

**Закладка style_** — закладка в DOCX, имя которой начинается с style_. По ней скрипт назначает стиль Word элементу в диапазоне закладки.

## Принцип согласования part_

Если во входном DOCX есть закладка part_ и в HTML есть одноименный якорь part_, содержимое диапазона закладки заменяется содержимым якоря. Если закладки нет, фрагмент HTML с этим именем не вставляется. Если закладка есть, а якоря нет, диапазон не меняется. Имена и число зон part_ произвольны при условии совпадения между HTML и шаблоном.

## Извлечение фрагмента из HTML

Фрагмент берется из разметки якоря part_: содержимое между открывающим тегом `<a name="part_…">` и закрывающим `</a>`, парно относящимся к этому якорю. Вложенные элементы, включая якоря style_, входят во фрагмент. При разборе HTML учитывается вложенность тегов `<a>`.

## Вставка во входной DOCX

Скрипт открывает входной DOCX и обрабатывает закладки part_ в порядке, безопасном для смещения диапазонов. Содержимое каждого диапазона удаляется и заменяется соответствующим HTML‑фрагментом через Word. Материал DOCX вне диапазонов part_ не изменяется. После вставки закладки part_ можно удалить.

## Имена закладок style_

Полное имя закладки состоит из префикса `style_`, закодированного имени стиля Word и незначимого хвоста. Хвост отделяется от закодированного имени последним символом подчеркивания в строке; он нужен только для уникальности закладок в одном документе и в имя стиля не входит.

При кодировании имени стиля каждый пробел заменяется на `_s`, каждое подчеркивание — на `__`. Пример: стиль `Heading 1` дает середину `Heading_s1`; с хвостом `d1e15` получается `style_Heading_s1_d1e15`.

При декодировании сначала снимают префикс `style_`, затем отбрасывают хвост (все после последнего `_`), в оставшейся строке заменяют `__` на `_`, затем `_s` на пробел. Результат должен совпадать с именем стиля во входном DOCX. Для `style_Heading_s1_d1e15` получается `Heading 1`.

## Применение стилей по style_

После вставки всех фрагментов part_ скрипт обрабатывает закладки style_ в выходном DOCX. Имя каждой закладки декодируется, как описано выше; найденный стиль назначается диапазону закладки (абзацный или символьный — по типу стиля в документе). Якоря style_ приходят в HTML внутри фрагментов part_ и после вставки должны оказаться в виде одноименных закладок Word. Механизмы part_ и style_ независимы: part_ определяет зону замены, style_ — оформление элементов внутри вставленного содержимого.

## Сбои

Сбой открытия файлов, недоступность Word или ошибка вставки или назначения стиля по закладке должны прерывать выполнение с сообщением. Отсутствие пары «закладка part_ — якорь part_» для отдельного имени не считается ошибкой.

## Интерфейс скрипта

Три аргумента: путь к HTML, путь ко входному DOCX, путь к выходному DOCX. Порядок шагов: вставка по part_, применение стилей по style_, сохранение выходного файла.
