# Скрипт `bookmarx.vbs`. Описание реализации

## Назначение документа

Документ описывает реализацию этапа `html2docx`, который выполняет скрипт `bookmarx.vbs`. Скрипт переносит фрагменты промежуточного HTML в шаблон Word по закладкам `part_`, затем назначает стили Word по закладкам `style_` и удаляет служебные подписи якорей. Скрипт сохраняет без изменений все участки шаблона вне закладок `part_` в выходном DOCX.

Для каждого шага документ указывает, как он выполнен и почему выбран именно такой способ. Большинство решений продиктовано поведением Word при импорте HTML и при автоматизации через COM.

Правило разметки HTML установлено решением ADR-0001 (документ `adr-0001-para-zakladok.md`).

## Термины

*HTML* — файл первого аргумента скрипта.

*Входной DOCX* — файл второго аргумента: шаблон Word с закладками `part_`.

*Выходной DOCX* — файл третьего аргумента, результат работы скрипта.

*Подпись якоря* — текст внутри открывающего или закрывающего служебного якоря HTML. В паре якорей подписи совпадают.

*Хвост уникальности* — часть атрибута `name` служебного якоря после префикса `part_` или `style_`. Хвост обеспечивает уникальность имени закладки в документе; форма хвоста не регламентируется.

*Открывающий якорь* — элемент HTML `<a name="part_<хвост>">подпись</a>` или `<a name="style_<хвост>">подпись</a>`, который отмечает начало фрагмента.

*Закрывающий якорь* — элемент HTML с именем `_` и полным именем открывающего якоря и с той же подписью внутри тега.

*Пара якорей* — открывающий и закрывающий якоря с именами `X` и `_X`.

*Фрагмент* — все между открывающим и закрывающим якорями пары.

*Служебная закладка* — закладка Word, которую Word формирует из открывающего или закрывающего якоря с префиксом `part_` или `style_`.

*Закладка якоря HTML* — служебная закладка, имя которой задаёт якорь в HTML (`part_<хвост>`, `style_<хвост>` или закрывающий вариант с префиксом `_`). На этапе удаления подписей её диапазон охватывает только текст подписи внутри якоря.

*Закладка зоны шаблона* — закладка `part_<подпись>` во входном DOCX, которая задаёт зону вставки. После замены содержимого зоны Word расширяет её диапазон на всё вставленное содержимое; эту закладку скрипт не очищает на этапе удаления подписей.

*Зона вставки* — диапазон закладки зоны шаблона `part_<подпись>`, где `<подпись>` совпадает с подписью соответствующей пары якорей в HTML.

*Исходный фрагмент* — диапазон открытого в Word HTML от начала открывающей закладки `part_<хвост>` до конца закрывающей закладки `_part_<хвост>`.

*Элемент со стилем* — диапазон выходного документа от начала открывающей закладки `style_<хвост>` до конца закрывающей закладки `_style_<хвост>`.

## Разметка во входном HTML

Каждый фрагмент HTML размечен парой якорей по правилу ADR-0001; правило едино для всех фрагментов.

```html
<a name="part_i737262">main</a> … содержимое … <a name="_part_i737262">main</a>
```

```html
<a name="style_i837364">Обычный козел</a> … содержимое … <a name="_style_i837364">Обычный козел</a>
```

Пары `part_` задают зоны вставки в шаблон. Пары `style_` размечают элементы внутри зон для назначения стилей Word.

Подпись внутри якоря нужна по следующей причине. Пустой якорь Word при импорте превращает в закладку нулевой длины. Закладку нулевой длины, которая стоит ровно на границе копируемого диапазона, Word при копировании не переносит. Word постоянно помещает такие закладки на границы зон: первый элемент зоны совпадает по началу с зоной, а последний элемент зоны совпадает по концу с зоной. Якорь с подписью Word превращает в закладку, которая охватывает текст подписи. Word переносит такую закладку целиком внутри копируемого диапазона вместе с ним.

Для зоны `part_` подпись совпадает с суффиксом имени закладки в шаблоне после префикса `part_`. Для `style_` подпись совпадает с именем стиля Word в шаблоне. В одном HTML не бывает двух пар `part_` с одинаковой подписью.

## Интерфейс скрипта

Интерпретатор `cscript` запускает скрипт; скрипт принимает три обязательных аргумента и один необязательный.

| Аргумент | Назначение |
|---|---|
| 1 | Путь к HTML |
| 2 | Путь ко входному DOCX, то есть к шаблону |
| 3 | Путь к выходному DOCX |
| 4 | Путь к файлу журнала; при отсутствии аргумента скрипт создает журнал рядом с HTML с именем вида `<имя>.bookmarx.log` |

Относительные пути скрипт приводит к абсолютным относительно текущего каталога. Признак абсолютного пути — наличие двоеточия или ведущей обратной косой черты. Скрипт при этом не проверяет существование файла, поскольку выходной файл и файл журнала на момент разбора аргументов еще не созданы.

## Общий порядок работы

Скрипт выполняет следующие шаги:

1. Открытие журнала.
2. Проверка наличия HTML и входного DOCX.
3. Создание экземпляра Word.
4. Копирование шаблона и HTML во временный каталог и открытие копий.
5. Включение показа скрытых закладок в обоих открытых документах.
6. Замена содержимого зон `part_`.
7. Закрытие открытого HTML.
8. Назначение стилей по закладкам `style_`.
9. Удаление служебных подписей.
10. Сохранение выходного DOCX.
11. Завершение Word и удаление временных копий.

Скрипт открывает журнал до обращения к Word и записывает в журнал каждое потенциально блокирующее действие до его выполнения. Если скрипт останавливает работу, последняя строка журнала указывает на точку остановки.

## Открытие документов

Скрипт открывает в Word не исходные файлы, а их копии во временном каталоге. Причина — механизм устойчивости Word. Если Word завершился аварийно с открытым документом, он заносит путь документа в список отключенных документов в разделе реестра `HKCU\Software\Microsoft\Office\16.0\Word\Resiliency\DisabledItems`. При следующем открытии того же пути Word показывает модальное окно с вопросом, открывать ли файл. Word запущен невидимым, поэтому окно некому закрыть, и вызов `Documents.Open` не возвращает управление. Свойство `DisplayAlerts` это окно не подавляет. Путь копии для механизма устойчивости каждый раз новый, и Word не распространяет на него прежние отметки.

Скрипт открывает HTML только для чтения, шаблон — для записи, а результат сохраняет под именем выходного DOCX.

## Показ скрытых закладок

Word считает скрытыми закладки, имя которых начинается с символа подчеркивания, и не включает их в коллекцию закладок документа. Имена всех закрывающих закладок начинаются с `_`. Поэтому сразу после открытия скрипт устанавливает свойство `Bookmarks.ShowHidden` в значение `True` у открытого HTML и у шаблона. Без этого скрипт не нашел бы ни одной закрывающей закладки.

## Определение зон вставки в шаблоне

Скрипт перебирает закладки шаблона и отбирает те, чье имя начинается с `part_`. Для каждой отобранной закладки скрипт запоминает имя и начальную позицию, после чего сортирует список по убыванию начальной позиции.

Обработка от конца документа к началу принципиальна. Вставка изменяет длину документа и смещает позиции закладок после измененной зоны. При обработке от конца к началу позиции еще не обработанных зон сохраняют действительность.

## Сопоставление зоны шаблона с парой в HTML

Имя закладки зоны в шаблоне имеет вид `part_<подпись>`, где `<подпись>` — текст, который должен стоять внутри открывающего якоря HTML. Скрипт ищет в открытом HTML открывающую закладку с префиксом `part_` (имя не начинается с `_`), у которой текст закладки совпадает с `<подпись>`, и закрывающую закладку `_` с тем же полным именем, что у найденной открывающей.

## Определение исходного фрагмента

**Жесткое правило**

Скрипт копирует содержимое между парой закладок `part_<хвост>` и `_part_<хвост>` в закладку шаблона `part_<подпись>`, где `<подпись>` — текст открывающей служебной закладки в HTML. Какие якоря стоят до пары и после нее и что лежит между парами, на границы фрагмента не влияют.

Исходный фрагмент — диапазон открытого HTML от начала открывающей закладки `part_<хвост>` до конца закрывающей закладки `_part_<хвост>`. В фрагмент входят подписи обеих служебных закладок пары и все вложенные пары `style_` вместе с их подписями. Скрипт не разбирает HTML текстуально: границы фрагмента задает только пара закладок, которую Word формирует при импорте.

Скрипт пропускает зону с предупреждением в журнале в следующих случаях:

- В HTML нет пары якорей `part_` с подписью, соответствующей имени закладки шаблона.
- В HTML нет открывающей или закрывающей закладки найденной пары.
- Фрагмент пуст.

## Замена содержимого зоны

Для каждой зоны скрипт присваивает свойству `FormattedText` диапазона зоны значение свойства `FormattedText` исходного фрагмента. Одно присваивание заменяет прежнее содержимое зоны новым вместе с оформлением и служебными закладками. Присваивание не зависит ни от буфера обмена, ни от выделения; объект `Selection` не используется, поскольку он относится к активному окну, а Word запущен невидимым.

Перед присваиванием скрипт проверяет, чем заканчиваются зона и фрагмент. Если последний символ зоны — знак конца абзаца, а последний символ фрагмента — нет, скрипт исключает знак конца абзаца шаблона из заменяемого диапазона и сохраняет его. Причина в следующем. Фрагмент заканчивается подписью закрывающей служебной закладки, а не концом абзаца. Если бы конец абзаца зоны был заменен, хвост фрагмента слился бы со следующим абзацем шаблона. Подпись последнего элемента зоны оказалась бы в чужом абзаце, и стиль этого элемента получил бы абзац шаблона, расположенный после зоны. Если скрипт сохранил знак конца абзаца, хвост фрагмента образует отдельный абзац, который скрипт затем удаляет вместе с подписями.

Если Word завершает присваивание ошибкой, скрипт записывает ошибку в журнал, пропускает зону и продолжает обработку со следующей зоны.

## Имена закладок style_ в HTML

Имя открывающей служебной закладки `style_` в HTML состоит из префикса `style_` и хвоста уникальности. Имя стиля Word в атрибут `name` не кодируют: имя стиля передают только подписью внутри якоря. Имя закрывающей закладки того же элемента — символ подчеркивания и полное имя открывающей.

Закладка относится к механизму `style_`, если ее имя начинается с `style_` и после префикса есть хвост уникальности. Скрипт не проверяет состав символов хвоста.

## Назначение стилей по закладкам style_

Скрипт выполняет проход после замены всех зон и до удаления служебных подписей, в выходном документе. К этому моменту подписи в закладках якорей HTML ещё на месте: по парам закладок скрипт определяет границы элементов.

Скрипт собирает имена открывающих закладок `style_` основного текста и обрабатывает собранный список. Скрипт формирует список заранее, а не по ходу обхода коллекции, поскольку назначение стилей изменяет документ.

Для каждой закладки скрипт читает имя стиля из текста открывающей закладки якоря HTML и ищет стиль в документе. Элемент со стилем — диапазон от начала закладки `style_<хвост>` до конца закладки `_style_<хвост>`. Скрипт назначает абзацный стиль каждому абзацу этого диапазона, кроме абзацев, которые целиком лежат в диапазоне открывающей или закрывающей закладки якоря пары. Символьный стиль скрипт назначает диапазону без этих абзацев-подписей. Скрипт не назначает стилю заголовка абзац с текстом подписи: иначе Word может изменить регистр подписи, и подпись останется в документе как лишний заголовок.

Скрипт продолжает проход и пропускает закладку с предупреждением в журнале в следующих случаях:

- В документе нет закрывающей закладки пары.
- В документе нет стиля с именем, совпадающим с подписью открывающей закладки.
- Скрипт не поддерживает такой тип стиля.

## Удаление служебных подписей

После назначения стилей скрипт удаляет подписи якорей HTML из выходного документа. Критерий — **имя закладки**, а не совпадение текста в документе с ожидаемой подписью. Содержимое подписи может отличаться регистром или оформлением после импорта и назначения стилей; скрипт на это не опирается.

Перед вставкой скрипт запоминает имена всех закладок зон шаблона `part_`. На этапе удаления скрипт перебирает закладки документа. Для каждой закладки якоря HTML (`part_<хвост>`, `style_<хвост>` и соответствующие закрывающие имена с префиксом `_`) скрипт удаляет **весь диапазон** `Bookmark.Range`, если закладка не пуста. Закладки зон шаблона в этот проход не входят: после вставки они охватывают всё содержимое зоны, и очистка их диапазона уничтожила бы вставленный текст.

Скрипт удаляет диапазоны в порядке убывания позиции начала, чтобы удаление одной закладки не смещало позиции остальных. После удаления диапазона скрипт проверяет абзац, в котором стояла подпись. Если в абзаце не осталось ничего, кроме пробелов, скрипт удаляет абзац целиком. Word образует такие абзацы из якорей, которые стоят между блочными элементами HTML: Word помещает текст таких якорей в отдельный абзац. Скрипт сохраняет абзац, в котором после удаления подписи остался текст.

Скрипт записывает ошибку при удалении отдельной закладки в журнал и не прерывает удаление остальных. Скрипт записывает в журнал число очищенных закладок якорей и число удаленных абзацев.

## Сохранение результата

Скрипт сохраняет выходной файл методом `SaveAs2` в формате `wdFormatXMLDocument`. Скрипт сохраняет выходной файл в любом случае, независимо от того, удалась ли замена всех зон, назначение всех стилей и удаление всех подписей. Отсутствие выходного файла недопустимо даже при ошибках на отдельных зонах, поскольку по результату нужно видеть, что именно получилось.

Для этого скрипт изолирует обработку каждой зоны, каждой закладки `style_` и каждой подписи: скрипт записывает ошибку в журнал и не прерывает цикл. Этапы замены зон и назначения стилей дополнительно обернуты обработчиками ошибок, после которых скрипт переходит к следующему этапу.

Скрипт завершает процесс из середины работы только до создания Word: при отсутствии аргументов и при отсутствии входных файлов. Если бы скрипт завершал процесс при открытых документах, Word оставался бы в памяти с незакрытыми документами. Накопление таких процессов приводит к аварийным завершениям Word и к появлению модального окна, описанного в разделе «Открытие документов».

## Журнал

Скрипт одновременно выводит каждую запись журнала на экран и дописывает ее в файл. Скрипт открывает и закрывает файл журнала на каждой записи, без буферизации. Буферизованный журнал при аварийном завершении процесса теряет последние строки, то есть именно ту часть, которая указывает на причину отказа.

Скрипт записывает в журнал следующие сведения:

- разобранный путь;
- размер входного файла;
- версия Word;
- путь и режим открытия каждого документа;
- перечень закладок `part_` шаблона с позициями;
- порядок обработки зон;
- сопоставление закладки шаблона с парой HTML и границы исходного фрагмента для каждой зоны;
- факт сохранения знака конца абзаца зоны;
- результат замены каждой зоны;
- число найденных закладок `style_`;
- число назначенных стилей;
- число пропущенных стилей;
- число очищенных закладок якорей HTML;
- число удаленных абзацев;
- факт сохранения выходного DOCX;
- факт завершения Word.

## Ограничения

Скрипт выполняет перенос по закладкам `part_`, назначение стилей по закладкам `style_` и удаление служебных подписей. Скрипт на этом этапе не строит оглавление.

После вызова `Quit` процесс Word не всегда завершается сразу. Если процесс переживает завершение скрипта, следующий запуск работает с уже существующим экземпляром Word. При сопровождении необходимо контролировать наличие процессов `WINWORD` после прогона.
