# Скрипт `bookmarx.vbs`. Описание реализации

## Назначение документа

Документ описывает реализацию этапа html2docx, выполняемого скриптом `bookmarx.vbs`. Скрипт переносит фрагменты промежуточного HTML в шаблон Word по закладкам part_, затем назначает стили Word по закладкам style_ и удаляет служебные маркеры. Все участки шаблона вне закладок part_ сохраняются в выходном DOCX без изменений.

Для каждого шага документ указывает, как он выполнен и почему выбран именно такой способ. Большинство решений продиктовано поведением Word при импорте HTML и при автоматизации через COM.

## Термины

*HTML* — файл первого аргумента скрипта.

*Входной DOCX* — файл второго аргумента: шаблон Word с закладками part_.

*Выходной DOCX* — файл третьего аргумента, результат работы скрипта.

*Маркер* — служебный текст `@#$$#@` внутри каждого служебного якоря HTML.

*Открывающий якорь* — элемент HTML `<a name="X">@#$$#@</a>`, отмечающий начало фрагмента.

*Закрывающий якорь* — элемент HTML `<a name="_X">@#$$#@</a>`, отмечающий конец фрагмента. Имя закрывающего якоря образуется приставкой `_` к имени открывающего.

*Пара якорей* — открывающий и закрывающий якоря с именами `X` и `_X`. *Фрагмент* — все, что находится между ними.

*Служебная закладка* — закладка Word, полученная из открывающего или закрывающего якоря с префиксом part_ или style_.

*Зона вставки* — диапазон закладки part_ во входном DOCX.

*Исходный фрагмент* — диапазон открытого в Word HTML от начала открывающей закладки `part_X` до конца закрывающей закладки `_part_X`.

*Элемент со стилем* — диапазон выходного документа от начала открывающей закладки `style_X` до конца закрывающей закладки `_style_X`.

## Разметка во входном HTML

Каждый фрагмент HTML размечен парой якорей. Правило разметки установлено решением ADR-0001 (документ `adr-0001-para-zakladok.md`) и едино для всех фрагментов: и для зон part_, и для элементов style_, и для абзацев, и для списков.

```html
<a name="part_main">@#$$#@</a> … содержимое … <a name="_part_main">@#$$#@</a>
```

Пары part_ задают зоны вставки в шаблон. Пары style_ размечают элементы внутри зон для назначения стилей Word.

Маркер внутри якоря нужен по следующей причине. Пустой якорь Word при импорте превращает в закладку нулевой длины. Закладку нулевой длины, стоящую ровно на границе копируемого диапазона, Word при копировании не переносит. Такие закладки оказываются на границах зон постоянно: первый элемент зоны начинается в той же точке, что и сама зона, а последний элемент заканчивается в той же точке. Якорь с маркером Word превращает в закладку, охватывающую маркер. Такая закладка целиком находится внутри копируемого диапазона и переносится вместе с ним.

## Интерфейс скрипта

Скрипт запускается интерпретатором `cscript` и принимает три обязательных аргумента и один необязательный.

| Аргумент | Назначение |
|---|---|
| 1 | Путь к HTML |
| 2 | Путь ко входному DOCX, то есть к шаблону |
| 3 | Путь к выходному DOCX |
| 4 | Путь к файлу журнала; при отсутствии аргумента журнал создается скриптом рядом с HTML с именем вида `<имя>.bookmarx.log` |

Относительные пути скрипт приводит к абсолютным относительно текущего каталога. Признак абсолютного пути — наличие двоеточия или ведущей обратной косой черты. Существование файла при этом не проверяется, поскольку выходной файл и файл журнала на момент разбора аргументов еще не созданы.

## Общий порядок работы

Скрипт выполняет следующие шаги:

1. Открытие журнала.
2. Проверка наличия HTML и входного DOCX.
3. Создание экземпляра Word.
4. Копирование шаблона и HTML во временный каталог и открытие копий.
5. Включение показа скрытых закладок в обоих открытых документах.
6. Замена содержимого зон part_.
7. Закрытие открытого HTML.
8. Назначение стилей по закладкам style_.
9. Удаление маркеров.
10. Сохранение выходного DOCX.
11. Завершение Word и удаление временных копий.

Журнал открывается до обращения к Word, а каждое потенциально блокирующее действие записывается в журнал до его выполнения. Если работа останавливается, последняя строка журнала указывает на точку остановки.

## Открытие документов

Скрипт открывает в Word не исходные файлы, а их копии во временном каталоге. Причина — механизм устойчивости Word. Если Word завершился аварийно с открытым документом, он заносит путь документа в список отключенных документов в разделе реестра `HKCU\Software\Microsoft\Office\16.0\Word\Resiliency\DisabledItems`. При следующем открытии того же пути Word показывает модальное окно с вопросом, открывать ли файл. Word запущен невидимым, поэтому окно некому закрыть, и вызов `Documents.Open` не возвращает управление. Свойство `DisplayAlerts` это окно не подавляет. Путь копии для механизма устойчивости каждый раз новый, и прежние отметки на него не распространяются.
HTML скрипт открывает только для чтения. Шаблон открывается для записи, результат сохраняется под именем выходного DOCX.

## Показ скрытых закладок

Word считает скрытыми закладки, имя которых начинается с символа подчеркивания, и не включает их в коллекцию закладок документа. Имена всех закрывающих закладок начинаются с `_`. Поэтому сразу после открытия скрипт устанавливает свойство `Bookmarks.ShowHidden` в значение `True` у открытого HTML и у шаблона. Без этого скрипт не нашел бы ни одной закрывающей закладки.

## Определение зон вставки в шаблоне

Скрипт перебирает закладки шаблона и отбирает те, чье имя начинается с part_. Для каждой отобранной закладки запоминаются имя и начальная позиция, после чего список сортируется по убыванию начальной позиции.

Обработка от конца документа к началу принципиальна. Вставка изменяет длину документа, и позиции закладок после измененной зоны смещаются. При обработке от конца к началу позиции еще не обработанных зон остаются действительными.

## Определение исходного фрагмента

**Жесткое правило: фрагмент между парой якорей `part_X` и `_part_X` копируется внутрь одноименной закладки `part_X`.** Какие якоря стоят до пары и после нее и что находится между парами, на границы фрагмента не влияет.

Исходный фрагмент — диапазон открытого HTML от начала закладки `part_X` до конца закладки `_part_X`. В фрагмент входят маркеры обеих закладок и все вложенные пары style_ вместе с их маркерами. Скрипт не разбирает HTML текстуально: границы фрагмента определяет только пара закладок, построенная Word при импорте.

Зона пропускается с предупреждением в журнале в следующих случаях:

- в шаблоне нет закладки part_ с таким именем;
- в HTML нет открывающей или закрывающей закладки пары;
- фрагмент получается пустым.

## Замена содержимого зоны

Для каждой зоны скрипт присваивает свойству `FormattedText` диапазона зоны значение свойства `FormattedText` исходного фрагмента. Одно присваивание заменяет прежнее содержимое зоны новым вместе с оформлением и служебными закладками. Присваивание не зависит ни от буфера обмена, ни от выделения; объект `Selection` не используется, поскольку он относится к активному окну, а Word запущен невидимым.

Перед присваиванием скрипт проверяет, чем заканчиваются зона и фрагмент. Если последний символ зоны — знак конца абзаца, а последний символ фрагмента — нет, знак конца абзаца шаблона исключается из заменяемого диапазона и сохраняется. Причина в следующем. Фрагмент заканчивается маркером закрывающей закладки, а не концом абзаца. Если бы конец абзаца зоны был заменен, хвост фрагмента слился бы со следующим абзацем шаблона. Закрывающий маркер последнего элемента зоны оказался бы в чужом абзаце, и стиль этого элемента получил бы абзац шаблона, расположенный после зоны. Сохраненный знак конца абзаца оставляет хвост фрагмента отдельным абзацем, который затем удаляется вместе с маркерами.

Если присваивание завершается ошибкой Word, ошибка записывается в журнал, зона пропускается, и обработка продолжается со следующей зоны.

## Имена закладок style_

Имя открывающей закладки style_ состоит из префикса `style_`, закодированного имени стиля Word и хвоста уникальности. Хвост отделяется последним символом подчеркивания; он обеспечивает уникальность имен закладок в документе и в имя стиля не входит.

При кодировании имени стиля каждый пробел заменяется на `_s`, каждое подчеркивание — на `__`. Стиль `Heading 1` дает середину `Heading_s1`, а вместе с хвостом `d1e15` получается имя `style_Heading_s1_d1e15`. Закрывающая закладка того же элемента называется `_style_Heading_s1_d1e15`.

При декодировании скрипт снимает префикс `style_`, отбрасывает все после последнего символа подчеркивания, в оставшейся строке заменяет `__` на `_`, а `_s` — на пробел. Результат должен совпадать с именем стиля в шаблоне.

Закладка относится к механизму style_, если ее имя начинается с `style_` и содержит после префикса символ подчеркивания, отделяющий хвост. Состав символов хвоста не проверяется.

## Назначение стилей по закладкам style_

Проход выполняется после замены всех зон и до удаления маркеров, в выходном документе. Маркеры к этому моменту должны оставаться на месте: по ним определяются границы элементов, а вместе с маркером Word удаляет и закладку.

Скрипт собирает имена открывающих закладок style_ основного текста и обрабатывает собранный список. Список формируется заранее, а не по ходу обхода коллекции, поскольку назначение стилей изменяет документ.

Для каждой закладки скрипт декодирует имя стиля и ищет стиль в документе. Элемент со стилем — диапазон от начала закладки `style_X` до конца закладки `_style_X`. Абзацный стиль назначается каждому абзацу этого диапазона, символьный — диапазону целиком. Поэтому абзац получает стиль один раз, а список — каждым своим пунктом, по одному и тому же правилу.

Закладка пропускается с предупреждением, и проход продолжается, в следующих случаях:

- нет закрывающей закладки пары;
- стиля с таким именем в документе нет;
- тип стиля не поддерживается.

## Удаление маркеров

После назначения стилей скрипт удаляет маркеры из выходного документа. Маркер удаляется только внутри служебной закладки, поэтому такой же текст в содержимом документа не затрагивается.

Скрипт перебирает служебные закладки part_ и style_, открывающие и закрывающие. Если текст, начинающийся в позиции начала закладки, совпадает с маркером, позиция маркера запоминается. Проверяется именно начало закладки, а не весь ее текст. Закладка part_ шаблона, у которой сохранен знак конца абзаца, продолжает существовать и охватывает всю вставленную зону, но начинается она по-прежнему с маркера.

Маркеры удаляются в порядке убывания позиции, чтобы удаление одного маркера не смещало позиции еще не удаленных. После удаления маркера скрипт проверяет абзац, в котором маркер находился. Если в абзаце не осталось ничего, кроме пробелов, абзац удаляется целиком. Такие абзацы образуются из якорей, стоящих между блочными элементами HTML: Word помещает текст таких якорей в отдельный абзац. Абзац, в котором после удаления маркеров остался текст, сохраняется.

Ошибка при удалении отдельного маркера записывается в журнал и не прерывает удаление остальных. В журнал записываются число удаленных маркеров и число удаленных абзацев.

## Сохранение результата

Выходной файл сохраняется методом `SaveAs2` в формате `wdFormatXMLDocument`. Сохранение выполняется **в любом случае**, независимо от того, удалась ли замена всех зон, назначение всех стилей и удаление всех маркеров. Отсутствие выходного файла недопустимо даже при ошибках на отдельных зонах, поскольку по результату нужно видеть, что именно получилось.

Для этого обработка каждой зоны, каждой закладки style_ и каждого маркера изолирована: ошибка записывается в журнал и не прерывает цикл. Этапы замены зон и назначения стилей дополнительно обернуты обработчиками ошибок, после которых скрипт переходит к следующему этапу.

Завершение процесса из середины работы применяется только до создания Word: при отсутствии аргументов и при отсутствии входных файлов. Если бы скрипт завершал процесс при открытых документах, Word оставался бы в памяти с незакрытыми документами. Накопление таких процессов приводит к аварийным завершениям Word и к появлению модального окна, описанного в разделе «Открытие документов».

## Журнал

Каждая запись журнала одновременно выводится на экран и дописывается в файл. Файл открывается и закрывается на каждой записи, без буферизации. Буферизованный журнал при аварийном завершении процесса теряет последние строки, то есть именно ту часть, которая указывает на причину отказа.

В журнал записываются следующие сведения:

- разобранные пути;
- размеры входных файлов;
- создание объекта Word и его версия;
- каждое открытие документа с указанием пути и режима;
- перечень закладок part_ шаблона с их позициями;
- порядок обработки зон;
- границы исходного фрагмента и зоны для каждой зоны;
- сохранение знака конца абзаца зоны;
- результат замены каждой зоны;
- число найденных закладок style_, число назначенных и пропущенных стилей;
- число удаленных маркеров и удаленных абзацев;
- сохранение результата и завершение Word.

## Ограничения

Скрипт выполняет перенос по закладкам part_, назначение стилей по закладкам style_ и удаление маркеров. Оглавление на этом этапе не строится.

После вызова `Quit` процесс Word не всегда завершается сразу. Если процесс переживает завершение скрипта, следующий запуск работает с уже существующим экземпляром Word. При сопровождении рекомендуется контролировать наличие процессов WINWORD после прогона.
