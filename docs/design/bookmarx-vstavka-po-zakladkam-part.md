# Скрипт `bookmarx.vbs`. Описание реализации

## Назначение документа

Документ описывает реализацию этапа `html2docx`, который выполняет скрипт `bookmarx.vbs`. Скрипт переносит фрагменты промежуточного HTML в шаблон Word по закладкам `part_`, затем назначает стили Word по закладкам `style_` и удаляет служебные маркеры. Скрипт сохраняет без изменений все участки шаблона вне закладок `part_` в выходном DOCX.

Для каждого шага документ указывает, как он выполнен и почему выбран именно такой способ. Большинство решений продиктовано поведением Word при импорте HTML и при автоматизации через COM.

## Термины

*HTML* — файл первого аргумента скрипта.

*Входной DOCX* — файл второго аргумента: шаблон Word с закладками `part_`.

*Выходной DOCX* — файл третьего аргумента, результат работы скрипта.

*Маркер* — служебный текст `@#$$#@` внутри каждого служебного якоря HTML.

*Открывающий якорь* — элемент HTML `<a name="X">@#$$#@</a>`, который отмечает начало фрагмента.

*Закрывающий якорь* — элемент HTML `<a name="_X">@#$$#@</a>`, который отмечает конец фрагмента. К имени открывающего якоря добавляют приставку `_`, чтобы получить имя закрывающего.

*Пара якорей* — открывающий и закрывающий якоря с именами `X` и `_X`.

*Фрагмент* — все между открывающим и закрывающим якорями пары.

*Служебная закладка* — закладка Word, которую Word формирует из открывающего или закрывающего якоря с префиксом `part_` или `style_`.

*Зона вставки* — диапазон закладки `part_` во входном DOCX.

*Исходный фрагмент* — диапазон открытого в Word HTML от начала открывающей закладки `part_X` до конца закрывающей закладки `_part_X`.

*Элемент со стилем* — диапазон выходного документа от начала открывающей закладки `style_X` до конца закрывающей закладки `_style_X`.

## Разметка во входном HTML

Каждый фрагмент HTML размечен парой якорей. Правило разметки установлено решением ADR-0001 (документ `adr-0001-para-zakladok.md`) и едино для всех фрагментов.

```html
<a name="part_main">@#$$#@</a> … содержимое … <a name="_part_main">@#$$#@</a>
```

Пары `part_` задают зоны вставки в шаблон. Пары `style_` размечают элементы внутри зон для назначения стилей Word.

Маркер внутри якоря нужен по следующей причине. Пустой якорь Word при импорте превращает в закладку нулевой длины. Закладку нулевой длины, которая стоит ровно на границе копируемого диапазона, Word при копировании не переносит. Word постоянно помещает такие закладки на границы зон: первый элемент зоны совпадает по началу с зоной, а последний элемент зоны совпадает по концу с зоной. Якорь с маркером Word превращает в закладку, которая охватывает маркер. Word переносит такую закладку целиком внутри копируемого диапазона вместе с ним.

## Интерфейс скрипта

Интерпретатор `cscript` запускает скрипт; скрипт принимает три обязательных аргумента и один необязательный.

| Аргумент | Назначение |
|---|---|
| 1 | Путь к HTML |
| 2 | Путь ко входному DOCX, то есть к шаблону |
| 3 | Путь к выходному DOCX |
| 4 | Путь к файлу журнала; при отсутствии аргумента скрипт создает журнал рядом с HTML с именем вида `<имя>.bookmarx.log` |

Относительные пути скрипт приводит к абсолютным относительно текущего каталога. Признак абсолютного пути — наличие двоеточия или ведущей обратной косой черты. Скрипт при этом не проверяет существование файла, поскольку выходной файл и файл журнала на момент разбора аргументов еще не созданы.

## Общий порядок работы

Скрипт выполняет следующие шаги:

1. Открытие журнала.
2. Проверка наличия HTML и входного DOCX.
3. Создание экземпляра Word.
4. Копирование шаблона и HTML во временный каталог и открытие копий.
5. Включение показа скрытых закладок в обоих открытых документах.
6. Замена содержимого зон `part_`.
7. Закрытие открытого HTML.
8. Назначение стилей по закладкам `style_`.
9. Удаление маркеров.
10. Сохранение выходного DOCX.
11. Завершение Word и удаление временных копий.

Скрипт открывает журнал до обращения к Word и записывает в журнал каждое потенциально блокирующее действие до его выполнения. Если скрипт останавливает работу, последняя строка журнала указывает на точку остановки.

## Открытие документов

Скрипт открывает в Word не исходные файлы, а их копии во временном каталоге. Причина — механизм устойчивости Word. Если Word завершился аварийно с открытым документом, он заносит путь документа в список отключенных документов в разделе реестра `HKCU\Software\Microsoft\Office\16.0\Word\Resiliency\DisabledItems`. При следующем открытии того же пути Word показывает модальное окно с вопросом, открывать ли файл. Word запущен невидимым, поэтому окно некому закрыть, и вызов `Documents.Open` не возвращает управление. Свойство `DisplayAlerts` это окно не подавляет. Путь копии для механизма устойчивости каждый раз новый, и Word не распространяет на него прежние отметки.

Скрипт открывает HTML только для чтения, шаблон — для записи, а результат сохраняет под именем выходного DOCX.

## Показ скрытых закладок

Word считает скрытыми закладки, имя которых начинается с символа подчеркивания, и не включает их в коллекцию закладок документа. Имена всех закрывающих закладок начинаются с `_`. Поэтому сразу после открытия скрипт устанавливает свойство `Bookmarks.ShowHidden` в значение `True` у открытого HTML и у шаблона. Без этого скрипт не нашел бы ни одной закрывающей закладки.

## Определение зон вставки в шаблоне

Скрипт перебирает закладки шаблона и отбирает те, чье имя начинается с `part_`. Для каждой отобранной закладки скрипт запоминает имя и начальную позицию, после чего сортирует список по убыванию начальной позиции.

Обработка от конца документа к началу принципиальна. Вставка изменяет длину документа и смещает позиции закладок после измененной зоны. При обработке от конца к началу позиции еще не обработанных зон сохраняют действительность.

## Определение исходного фрагмента

**Жесткое правило**

Скрипт копирует фрагмент между парой якорей `part_X` и `_part_X` в одноименную закладку `part_X`. Какие якоря стоят до пары и после нее и что лежит между парами, на границы фрагмента не влияет.

Исходный фрагмент — диапазон открытого HTML от начала закладки `part_X` до конца закладки `_part_X`. В фрагмент входят маркеры обеих закладок и все вложенные пары `style_` вместе с их маркерами. Скрипт не разбирает HTML текстуально: границы фрагмента задает только пара закладок, которую Word формирует при импорте.

Скрипт пропускает зону с предупреждением в журнале в следующих случаях:

- В шаблоне нет закладки `part_` с таким именем.
- В HTML нет открывающей или закрывающей закладки пары.
- Фрагмент пуст.

## Замена содержимого зоны

Для каждой зоны скрипт присваивает свойству `FormattedText` диапазона зоны значение свойства `FormattedText` исходного фрагмента. Одно присваивание заменяет прежнее содержимое зоны новым вместе с оформлением и служебными закладками. Присваивание не зависит ни от буфера обмена, ни от выделения; объект `Selection` не используется, поскольку он относится к активному окну, а Word запущен невидимым.

Перед присваиванием скрипт проверяет, чем заканчиваются зона и фрагмент. Если последний символ зоны — знак конца абзаца, а последний символ фрагмента — нет, скрипт исключает знак конца абзаца шаблона из заменяемого диапазона и сохраняет его. Причина в следующем. Фрагмент заканчивается маркером закрывающей закладки, а не концом абзаца. Если бы конец абзаца зоны был заменен, хвост фрагмента слился бы со следующим абзацем шаблона. Закрывающий маркер последнего элемента зоны оказался бы в чужом абзаце, и стиль этого элемента получил бы абзац шаблона, расположенный после зоны. Если скрипт сохранил знак конца абзаца, хвост фрагмента образует отдельный абзац, который скрипт затем удаляет вместе с маркерами.

Если Word завершает присваивание ошибкой, скрипт записывает ошибку в журнал, пропускает зону и продолжает обработку со следующей зоны.

## Имена закладок style_

Имя открывающей закладки `style_` состоит из префикса `style_`, имени стиля Word в закодированном виде и хвоста уникальности. Хвост — часть имени после последнего символа подчеркивания; он обеспечивает уникальность имен закладок в документе и в имя стиля не входит.

При кодировании имени стиля схема кодирования заменяет каждый пробел на `_s`, а каждое подчеркивание — на `__`. Стиль `Heading 1` дает середину `Heading_s1`, а вместе с хвостом `d1e15` дает имя `style_Heading_s1_d1e15`. Имя закрывающей закладки того же элемента — `_style_Heading_s1_d1e15`.

При декодировании скрипт снимает префикс `style_`, отбрасывает все после последнего символа подчеркивания, в оставшейся строке заменяет `__` на `_`, а `_s` — на пробел. Результат должен совпадать с именем стиля в шаблоне.

Закладка относится к механизму `style_`, если ее имя начинается с `style_` и содержит после префикса символ подчеркивания, который отделяет хвост. Скрипт не проверяет состав символов хвоста.

## Назначение стилей по закладкам style_

Скрипт выполняет проход после замены всех зон и до удаления маркеров, в выходном документе. К этому моменту скрипт еще не удалял маркеры: по ним он определяет границы элементов, а вместе с маркером Word удаляет и закладку.

Скрипт собирает имена открывающих закладок `style_` основного текста и обрабатывает собранный список. Скрипт формирует список заранее, а не по ходу обхода коллекции, поскольку назначение стилей изменяет документ.

Для каждой закладки скрипт декодирует имя стиля и ищет стиль в документе. Элемент со стилем — диапазон от начала закладки `style_X` до конца закладки `_style_X`. Скрипт назначает абзацный стиль каждому абзацу этого диапазона, а символьный — диапазону целиком. Поэтому абзац получает стиль один раз, а список — каждым своим пунктом, по одному и тому же правилу.

Скрипт продолжает проход и пропускает закладку с предупреждением в журнале в следующих случаях:

- В документе нет закрывающей закладки пары.
- В документе нет стиля с декодированным именем.
- Скрипт не поддерживает такой тип стиля.

## Удаление маркеров

После назначения стилей скрипт удаляет маркеры из выходного документа. Скрипт удаляет маркер только внутри служебной закладки, поэтому такой же текст в содержимом документа не затрагивает.

Скрипт перебирает служебные закладки `part_` и `style_`, открывающие и закрывающие. Если текст в позиции начала закладки совпадает с маркером, скрипт запоминает позицию маркера. Скрипт проверяет именно начало закладки, а не весь ее текст. Закладка `part_` шаблона, для которой скрипт сохранил знак конца абзаца, по-прежнему существует и охватывает всю вставленную зону; маркер по-прежнему стоит в начале этой закладки.

Скрипт удаляет маркеры в порядке убывания позиции, чтобы удаление одного маркера не смещало позиции еще не удаленных. После удаления маркера скрипт проверяет абзац, в котором стоял маркер. Если в абзаце не осталось ничего, кроме пробелов, скрипт удаляет абзац целиком. Word образует такие абзацы из якорей, которые стоят между блочными элементами HTML: Word помещает текст таких якорей в отдельный абзац. Скрипт сохраняет абзац, в котором после удаления маркеров остался текст.

Скрипт записывает ошибку при удалении отдельного маркера в журнал и не прерывает удаление остальных. Скрипт записывает в журнал число удаленных маркеров и число удаленных абзацев.

## Сохранение результата

Скрипт сохраняет выходной файл методом `SaveAs2` в формате `wdFormatXMLDocument`. Скрипт сохраняет выходной файл в любом случае, независимо от того, удалась ли замена всех зон, назначение всех стилей и удаление всех маркеров. Отсутствие выходного файла недопустимо даже при ошибках на отдельных зонах, поскольку по результату нужно видеть, что именно получилось.

Для этого скрипт изолирует обработку каждой зоны, каждой закладки `style_` и каждого маркера: скрипт записывает ошибку в журнал и не прерывает цикл. Этапы замены зон и назначения стилей дополнительно обернуты обработчиками ошибок, после которых скрипт переходит к следующему этапу.

Скрипт завершает процесс из середины работы только до создания Word: при отсутствии аргументов и при отсутствии входных файлов. Если бы скрипт завершал процесс при открытых документах, Word оставался бы в памяти с незакрытыми документами. Накопление таких процессов приводит к аварийным завершениям Word и к появлению модального окна, описанного в разделе «Открытие документов».

## Журнал

Скрипт одновременно выводит каждую запись журнала на экран и дописывает ее в файл. Скрипт открывает и закрывает файл журнала на каждой записи, без буферизации. Буферизованный журнал при аварийном завершении процесса теряет последние строки, то есть именно ту часть, которая указывает на причину отказа.

Скрипт записывает в журнал следующие сведения:

- разобранный путь;
- размер входного файла;
- версия Word;
- путь и режим открытия каждого документа;
- перечень закладок `part_` шаблона с позициями;
- порядок обработки зон;
- границы исходного фрагмента и зоны для каждой зоны;
- факт сохранения знака конца абзаца зоны;
- результат замены каждой зоны;
- число найденных закладок `style_`;
- число назначенных стилей;
- число пропущенных стилей;
- число удаленных маркеров;
- число удаленных абзацев;
- факт сохранения выходного DOCX;
- факт завершения Word.

## Ограничения

Скрипт выполняет перенос по закладкам `part_`, назначение стилей по закладкам `style_` и удаление маркеров. Скрипт на этом этапе не строит оглавление.

После вызова `Quit` процесс Word не всегда завершается сразу. Если процесс переживает завершение скрипта, следующий запуск работает с уже существующим экземпляром Word. При сопровождении необходимо контролировать наличие процессов `WINWORD` после прогона.
